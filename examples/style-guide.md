# Example Additional Style Guide

- Follow the selected PPT template style profile as the primary design system.
- Use concise claim-like titles.
- Prefer dense but orderly scientific layouts.
- Use tables for QC metrics and model comparisons.
- Use formula/callout boxes for statistical definitions.
- Avoid decorative images unrelated to genomics or population structure.
- Keep all labels, sample IDs, population names, and parameter notation exact.
